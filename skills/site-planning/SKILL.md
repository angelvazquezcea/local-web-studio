# Site planning

## 1. Answer the decision questions (from client.md)

| Question | If yes | If no |
|---|---|---|
| Do they sell to the public? | Products/services section, prices if they want | No shop, no prices; focus on trust/image |
| Can customers visit? | Visit info, directions, hours, booking/visit form | **No visit offers anywhere**; say why if useful (e.g. biosecurity) |
| Do they take bookings? | Booking CTA (link to their tool/platform) above the fold | Contact CTA only |
| Online payment needed? | Separate scope (shop/booking engine) | Never add carts "just in case" |
| Multiple audiences? (customers, staff, suppliers) | Separate sections or pages per audience | Single path |
| Content volume large? (menu, many rooms, catalogue, many services) | Multi-page | **One page** (most local sites) |
| SEO for distinct services/places? | One page per main service/town | Sections |
| Languages? | See `multilingual-sites` | Single language |

Write the answers as "Decisions" in `client.md`.

## 2. Default one-page order (adapt)

1. **Hero** — who/what/where in one line + primary CTA (call/WhatsApp/book) + strongest image.
2. **Proof strip** — 2–4 facts (years, hectares, rooms, certifications, rating).
3. **What we do / offer** — products, services, rooms, menu highlights.
4. **Why us** — differentiators in concrete facts.
5. **Story / people** — the family, the place, photos of real people (with permission).
6. **How it works / what to expect** — process, booking steps, delivery, visit rules.
7. **Gallery** — curated, 6–12 images, lightweight.
8. **Reviews** — real, with source.
9. **FAQ** — the questions they get by phone (hours, parking, pets, prices, area served).
10. **Contact & map** — all phones (call + WhatsApp), email, address, hours, map, directions.
11. **Footer** — legal links, social, small credit to the studio if agreed.

Multi-page: Home (summary of the above) + one page per main offer + About + Contact + legal.

## 3. CTA plan

- One **primary action** per business (call for trades, WhatsApp for small shops, book for
  tourism, quote request for B2B). It appears in the hero, after key sections, and in the
  sticky mobile bar.
- Secondary actions: directions, email, social.

## 4. Output

A sitemap + for each section: purpose, content source (client words/assets), CTA, notes
(e.g. "replace stock photo"). Save to `client.md` under "Site plan" or `docs/site-plan.md`.
Flag missing content as a list to request from the client.
