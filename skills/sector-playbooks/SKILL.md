# Sector playbooks

Load the matching reference file before the discovery call and again before planning the
site. If the business mixes sectors (a farm with a shop and a rural house), read each and
merge, keeping the strictest rules.

| Sector | File |
|---|---|
| Farms, livestock, crops, cooperatives | `references/farms-agriculture.md` |
| Agricultural machinery, dealers, contractors | `references/agricultural-machinery.md` |
| Rural tourism, rural houses, small hotels, campsites | `references/rural-tourism.md` |
| Food producers: bakeries, cheese, wine, honey, preserves | `references/food-producers.md` |
| Restaurants, bars, cafés | `references/restaurants.md` |
| Trades: plumbers, electricians, builders, carpenters, roofers | `references/trades.md` |
| Car workshops, tyres, bodyshops | `references/car-workshops.md` |
| Hair, beauty, barbers, aesthetics | `references/beauty.md` |
| Health: dentists, physio, clinics, vets | `references/health-clinics.md` |
| Shops and local retail | `references/retail-shops.md` |
| Professional services: accountants, gestorías, lawyers, architects | `references/professional-services.md` |

If no file fits, use the closest one and the generic flow in `site-planning`, and offer to
write a new reference file for that sector afterwards (`references/<sector>.md`, same headings).

Each file has the same headings: **Goals · Audiences · Must-have sections · Hard rules ·
Schema · CTAs · Photos · FAQ ideas · Discovery questions · Pitfalls · Upsells**.

Regulations are noted as reminders to check, with an EU/Spain bias where relevant; confirm the
current rules for the client's jurisdiction.
